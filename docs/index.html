Quiero organizar mi negocio ↗

En los cuatro paquetes: 14 días de corrección de errores del alcance entregado. Textos, logo, fotografías y datos los proporciona el cliente.

Precios en dólares estadounidenses. Web Inicio no incluye formulario, panel, reservas ni pagos en línea. Su alojamiento estático puede usar un plan gratuito; un dominio propio es opcional. En los demás paquetes, alojamiento y servicios se detallan en la propuesta. Dominio, correo, licencias, comisiones de pago y mantenimiento recurrente se cotizan por separado. La propuesta detalla el total y los impuestos aplicables antes de contratar.

*Los plazos comienzan al recibir los materiales y accesos completos y confirmar el inicio. Páginas adicionales, productos con variantes, pagos con tarjeta, integraciones fiscales y código fuente de sistemas licenciados no están incluidos. Gestión Inicial configura una solución existente; el desarrollo de software a medida se cotiza aparte.

Antes de comenzar

¿Cuánto cuesta un proyecto?

Puedes comenzar con Web Inicio desde US$99: una página de hasta tres secciones y enlaces de contacto, sin formulario ni panel. Web Esencial desde US$199 añade hasta cinco secciones y formulario. Las otras opciones comienzan en US$449 para una tienda inicial y US$599 para implementar el sistema base de gestión. Cada paquete tiene límites definidos; recibirás una propuesta con el alcance, costos adicionales e impuestos aplicables antes de contratar.

¿Pueden mejorar una web o sistema existente?

Sí. Primero revisamos su estado y los accesos disponibles para definir qué se puede adaptar y qué requiere un desarrollo adicional.

¿Qué necesito para empezar?

Una descripción del problema y, si existen, enlaces de referencia, materiales de marca y prioridades. Los accesos y documentos necesarios se coordinan después de definir el alcance.

¿Incluyen hosting, dominio y soporte?

Se especifican en cada propuesta. Las licencias, el alojamiento, el dominio y el soporte continuo se acuerdan antes de contratar.
